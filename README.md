# Bank Loan & Credit Risk Analysis

## Project Overview
This project focuses on analyzing bank loan application data to understand loan approval patterns and identify factors associated with loan approval and rejection.

The analysis was carried out using Microsoft Excel and Power BI, with the aim of transforming raw data into meaningful insights that can support better lending decisions.

## Tools Used
- **Microsoft Excel:** Data cleaning, data exploration, analysis and insight generation.
- **Power BI:** Data visualization and interactive dashboard development.

## Key Business Questions
- What percentage of loan applications were approved and rejected?
- How does credit history relate to loan approval?
- Does education level influence loan approval patterns?
- What patterns can be identified from the loan application data?

## Key Insights

- Out of 564 applications analyzed, 385 (68.26%) were approved, while 179 (31.74%) were rejected.
- Applicants in the CH1 category recorded a significantly higher approval rate (79.58%) than those in the CH0 category (7.87%).
- Graduates recorded a 70.83% approval rate, compared to 61.19% for non-graduates.

## Recommendations

- Give particular attention to credit history during loan assessment, as the analysis shows a strong relationship between the credit history categories and approval outcomes.
- Review rejected applications to identify areas where applicants may improve their eligibility.
- Avoid using educational qualification as a standalone lending criterion, since the difference in approval rates does not establish causation.
- Continue monitoring loan approval patterns to support informed lending decisions.
